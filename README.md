# DANI Reader Web

Reusable, local-first EPUB reading infrastructure for communities using Persian, Arabic, Dari, Pashto and Urdu. This standalone edition adapts the existing DANI / Readest reading UI and a pinned Foliate engine. It gives other developers a working library, renderer, state adapter and original RTL fixtures to extend.

**Status: in development; no public release yet.** The production bundle and local Windows Chrome reading increment run. Final functional/security review and publication are pending. The Android edition is a separate work in development. [rtlpub](https://github.com/qaribi/rtlpub) is the released offline publishing preflight component.

## Run and build

Use Node 24.19.0 and npm 12.2.0. Dependencies are exact in `package-lock.json`; install scripts are disabled.

```sh
npm ci --ignore-scripts
npm test
npm run build
npm run preview -- --port 5187
```

Open the printed loopback URL and import a local, unencrypted EPUB 3. `public/fixtures` contains original test books, generated by `python scripts/generate-fixtures.py`. No account or backend is required. Imported books and notes stay in the browser's IndexedDB on this origin. Clearing browser storage removes them; this release does not offer backup or cloud synchronization.

## Features and boundaries

| Feature | Implementation | Verification stage |
| --- | --- | --- |
| Local import/library and content-hash identity | Implemented | Windows Chrome import/reload; ZIP rejection tests |
| EPUB rendering, TOC and page navigation | Existing core adapted | Windows Chrome original RTL books |
| In-book search, highlights, notes and bookmarks | Implemented | Search/lifetime tests; Chrome chapter-return, deletion and save/exit checks |
| Reading position and font size/line height/theme/flow | Implemented | Chrome reopen/settings checks; fixed-layout preserves publisher styling |
| Persian, Arabic, Dari, Pashto and Urdu original content fixtures | Included | Rendered synthetic examples; native-language review welcome |
| PDF, DRM, remote catalogues, accounts, cloud sync, mobile packaging | Outside this Web edition | Not implemented |

The interface currently uses Persian. The four-language mission text below is documentation, not a claim that the interface has four translated versions. The rendered language checks use system fonts and original short examples; they do not establish comprehensive typography coverage.

Both reflowable and fixed-layout synthetic EPUBs render in the tested Chrome increment. Fixed-layout font size, line height and theme controls are disabled to preserve the publisher's page geometry. A resource-rich original EPUB with 250 additional resources imports and opens; an oversized resource manifest is rejected before it enters the library.

## Reuse the components

- `src/library/archive.ts`: bounded local EPUB import; produces detached resource bytes and a SHA-256 book identity.
- `src/library/database.ts`: local library, atomic revision-based state updates and reading settings.
- `src/library/local-transport.ts`: a working implementation of the six-operation reader host contract, scoped to one local book.
- `src/reader/ReaderPage.tsx`: existing reading UI with publication, library, settings and exit props.
- `src/reader/publication.ts`: controlled resource loader and publication markup/CSS sanitization.
- `vendor/foliate-js`: fixed upstream engine and documented security patches.

`src/App.tsx` is the working integration example: import a file with `importEpub`, persist it with `LocalLibrary.put`, then render `ReaderPage`. To supply another storage adapter, implement `HostTransport.control/resource` and preserve session, byte, revision and cancellation bounds; do not replace the publication isolation rules. Add an original language entry to the fixture generator, regenerate the EPUBs, run ZIP/search tests and inspect the rendered content in the target browser. Extend the UI through typed props and the bounded host contract rather than embedding private service dependencies.

## فارسی

کتاب و ابزار مطالعه باید برای جامعه‌های فارسی، عربی، دری، پشتو و اردو خوب کار کنند. هدف دانی فراهم‌کردن کد قابل بازاستفاده، رابط‌های مستند و نمونه‌های آزمایشی با متن تألیفی است تا توسعه‌دهندگان آسان‌تر ریدرهای توانمند بسازند. نسخهٔ وب مستقل در حال توسعه است و کتابخانهٔ محلی، نمایش EPUB، فهرست، جست‌وجو، یادداشت، نشانک، محل آخر مطالعه و تنظیمات را به موتور موجود متصل می‌کند. نمونهٔ قابل بازتولید، گزارش خطا و مشارکت در توسعه به بهبود آن کمک می‌کند.

## العربية

ينبغي أن تعمل الكتب وأدوات القراءة جيدًا للمجتمعات التي تستخدم الفارسية والعربية والدَرية والبشتوية والأردية. يوفّر داني مكوّنات مفتوحة قابلة لإعادة الاستخدام وواجهات موثّقة ونصوص اختبار أصلية، لتسهيل بناء قارئات غنية بالميزات. إصدار الويب المستقل قيد التطوير؛ يربط مكتبة محلية وعرض EPUB والفهرس والبحث والملاحظات والعلامات المرجعية وموضع القراءة والإعدادات بالمحرّك الموجود. نرحّب بالأمثلة القابلة لإعادة الإنتاج وتقارير الأخطاء والمساهمات.

# Local publication security boundary

The first verification target is Windows Chrome. Tests of this independent composition do not qualify Safari/WebKit, Android WebView or native Android. A separate origin is recommended for deployment: other trusted scripts on the same origin can access its IndexedDB. No backend, account, publisher authority, DRM grant or private API is part of this application.

EPUB files are untrusted. Import is bounded to 32 MiB compressed input, 512 ZIP entries, 2 MiB per inflated resource and 64 MiB total inflated bytes. Duplicate/escaping paths, ZIP encryption, special file entries, directory payloads, unsupported compression and excessive declared ratios are rejected. Actual streamed bytes are charged before storage; CRC is checked. Library storage is limited to 64 books and 128 MiB expanded content. XML is UTF-8 only, with DTD/entity/null-byte rejection and bounded element count/depth. Remote OPF/manifest resource references and encrypted EPUBs are refused at admission. Embedded remote image, SVG and CSS references are stripped or blocked at rendering; their presence alone does not reject the entire book. These are conservative reader admission rules, not a complete EPUB conformance validator.

The static application ships its CSP as an early HTML meta element, not a response header. Production `connect-src` is restricted to the application's own origin, with no broad loopback WebSocket allowance. Deployers should additionally serve the same policy as a response header. The engine's three iframe sandboxes omit `allow-scripts`. Publication HTML has script/connect/frame/object/form CSP restrictions; active elements, event handlers, SVG animation/set/foreignObject and remote resource URLs are stripped. CSS escapes/imports/executable constructs and non-local URLs are refused. The pinned loader does not return remote content URLs. Actual SVG, CSS, image, font and script probes use a private loopback observation sink; source inspection alone is insufficient evidence of this boundary.

Local state belongs to a content hash and one session. Updates check the stored revision atomically; abort, close and stale consumers retire pending operations. Explicit exit waits for accepted writes before retiring the reader. Abrupt browser termination cannot guarantee unfinished writes. Binary resources are detached copies with checked byte lengths. Search is limited to 100 results and 256 query characters. Control requests are limited to 16 KiB, resource manifests to 128 KiB and serialized reading state to 256 KiB. Admission validates the manifest before storing the book. Notes are limited to 2,048 characters. There are no automatic uploads or external publication-font downloads.

Browser storage is not encrypted and is not a backup. A malicious browser extension, compromised application deployment or another authorized same-origin script is outside this publication isolation boundary. Report a vulnerability privately through the maintainer's GitHub contact route with a synthetic minimal reproduction, without secrets or private books.
